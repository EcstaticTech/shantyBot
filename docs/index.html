Quick-Start Deployment

Deploy `shantyBot` instantly using Docker Compose or configure a standard local Python virtual environment.

Primary Deployment — Docker Compose 
# docker-compose.yml
version: '3.8'
services:
  shantybot:
    image: ghcr.io/ecstatictech/shantybot:latest
    container_name: shantybot
    restart: unless-stopped
    ports:
      - "127.0.0.1:8000:8000"
    volumes:
      - ./config.yaml:/app/config.yaml:ro
      - ./media/shanties:/app/media/shanties
      - ./media/ambient:/app/media/ambient
      - ./media/cache:/app/media/cache
Manual Installation — Local Python Virtual Environment 
# Clone repository and set up Python environment
git clone https://github.com/ecstatictech/shantybot.git
cd shantybot
python3 -m venv .venv
source .venv/bin/activate  # On Windows use: .venv\Scripts\activate

# Install project dependencies
pip install -r requirements.txt

# Copy configuration template and edit credentials
cp config.example.yaml config.yaml

# Launch shantyBot audio engine & web board
python3 main.py

Configuration Reference & Parameters

Full reference of configuration keys supported in `config.yaml` for bot authentication, media path bindings, and web server configuration.

Parameter Name Default Value Config Key / Path Description & Operational Usage
token "YOUR_DISCORD_BOT_TOKEN_HERE" bot.token Discord application bot token used for gateway connection and API authentication.
command_prefix "/shanty" bot.command_prefix Slash command prefix for disnake routing and legacy command matching.
idle_disconnect_seconds 180 bot.idle_disconnect_seconds Inactivity timeout in seconds before automatically leaving empty voice channels.
allowed_playlist_ids [] bot.allowed_playlist_ids Allowed list of YouTube playlist IDs permitted for queue batch imports.
media_directory "./media/shanties" paths.media_directory Local filesystem directory housing primary sea shanty audio tracks (.mp3, .flac, .opus).
ambient_directory "./media/ambient" paths.ambient_directory Local filesystem path storing ambient background loops and atmospheric soundscapes.
youtube_cache_directory "./media/cache" paths.youtube_cache_directory Storage path for yt-dlp stream downloads and cached FFmpeg JIT Opus chunks.
web.host "127.0.0.1" web.host Bind IP address for the embedded FastAPI Web Status Board service.
web.port 8000 web.port HTTP port serving the web status interface and health check API endpoints.
web.public_url "https://your-domain.com" web.public_url Publicly accessible base URL used for telemetry callbacks and dashboard sharing.

System Features & Architecture

Core architectural principles behind shantyBot's high-performance audio engine and zero-downtime resilience.

JIT Opus Engine

Dynamic FFmpeg audio transcoding with intelligent chunk caching. Converts multi-format audio streams on-the-fly to 48kHz 16-bit stereo Opus frames for zero-latency Discord playback.

Zero-Latency Audio

Web Status Board

Lightweight embedded status dashboard running on port 8000. Exposes real-time active voice session metrics, playback status, track queues, and health check telemetry via FastAPI.

Port 8000 Telemetry

Channel State Isolation

Strict isolation between voice channels. Maintains independent playback queues, audio transformers, volume controls, and session state engines across multiple guilds simultaneously.

Multi-Guild Support

Empty Directory Safety

Resilient daemon initialization with non-blocking unmounted media warnings. Gracefully handles missing sound libraries without crashing the Discord bot or Web Status Board daemons.

Fault Tolerant
